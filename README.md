# هيفن العقارية — Haven Realty

صفحة هبوط لوكالة عقارية: عقارات للبيع والإيجار مع بحث وتصفية تعمل على إعلانات تجريبية، وخدمات، ووكلاء، وآراء تجريبية، ورسوم بعناصر نائبة `{{...}}`، وأسئلة شائعة، ونموذج طلب معاينة مع تحقق وحفظ في المتصفح.

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
npm run preview
```

ثنائية اللغة (العربية RTL والإنجليزية LTR) مع زر تبديل وحفظ اللغة في `localStorage`. لا توجد متغيرات بيئة.
